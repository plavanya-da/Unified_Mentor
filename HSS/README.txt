Predictive Forecasting of Care Load & Placement Demand — Dashboard

RUN:
  pip install -r requirements.txt
  python -m streamlit run app.py

This package is a no-CSV-upload demonstration dashboard.
The HHS banner image is included as hhsgov_cover.jpg; keep it beside app.py.
Data are simulated and are not official HHS statistics. Do not use for operational decisions.
Forecast methods and KPI proxies require validation with authorized historical data.
